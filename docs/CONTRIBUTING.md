# Contributing

Open changes from a feature branch and link the active Spec Kit requirement. Keep commits focused, include automated and simulator evidence for behavior changes, and request maintainer review before merging.

Contributors must follow `AGENTS.md`, the project constitution, the MIT license, and respectful professional conduct. The repository does not yet carry a separate Code of Conduct; until one is adopted, harassment, discrimination, disclosure of private data, malicious code, and secret/signing-key commits are not accepted.

Timing, scoring, storage, activity-recording, resource, and input changes require explicit regression coverage. Add device IDs only after validation. Do not add network access, telemetry, third-party dependencies, generated artifacts, debug tracing, or speculative frameworks without an approved specification and supply-chain/privacy review.
